# Devendra Reddy Bala - Developer Portfolio

A sleek, responsive, and minimalist developer portfolio built with **React**, **Vite**, and **Tailwind CSS**. Designed specifically for students and early-career software engineers to showcase projects, skills, education, and credentials with elegance.

## 🚀 Key Features

- **Clean Minimalist Design**: Clean typography (Plus Jakarta Sans), balanced spacing, and subtle micro-interactions.
- **Light & Dark Mode**: Persistent theme toggle with automatic system preference detection.
- **Centralized Data**: Easily update your name, links, projects, skills, and bio from a single file: `src/data/portfolioData.js`.
- **Interactive Sections**:
  - **Hero**: Compelling intro, status badge ("Actively seeking roles"), quick CTA buttons, and social links.
  - **About**: Journey, academic focus, core strengths, and education spotlight.
  - **Skills**: Filterable categorized technical stack (Languages, Frontend, Backend, Tools & Fundamentals).
  - **Projects**: Filterable projects grid (Full Stack, Frontend, AI/Web) with live links, source code, and key impact points.
  - **Experience & Education**: Timeline comparing work/leadership experience and academic credentials.
  - **Certifications & Achievements**: Verified badges and competitive programming highlights.
  - **Contact**: Direct details with one-click copy email button, and an interactive message form with mailto fallback.
  - **Reading Progress Bar & Smooth Scroll**: Visual progress bar at the top of the viewport.

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production build will be generated in the `dist/` directory.

## 📝 Customization

All your portfolio data is located in:
👉 [`src/data/portfolioData.js`](./src/data/portfolioData.js)

To customize:
1. Open `src/data/portfolioData.js`.
2. Edit your name, email, GitHub/LinkedIn URLs, and resume link.
3. Update or add your own projects, skills, and certifications.
4. Changes will hot-reload immediately in your browser!
